# 余韵 · Echoes of Lyric

一份可以随身带走的诗词摘录。现代信笺式界面、书签分类、宽而薄的诗句展示条。全部前端打包为一个 HTML，诗集使用可直接阅读的 JSON。

在线查询现已改为 **浏览器直连 Tavily 搜索 API**，无需服务器、域名或网站 Cookie。应用不直接抓取任何诗词网站，也不限定搜索来源；候选由搜索 API 返回的网页摘要提取。

## 直接使用

1. 双击 `dist/echoes_of_lyric.html`，建议使用 Windows Chrome 或 Edge。可以把这个文件放到任意目录，包括中文及含空格的目录。
2. 点击顶部“设置”图标，填写自己的 Tavily API Key 并保存。已有 Key 可直接粘贴；新用户在 [Tavily 控制台](https://app.tavily.com) 获取。
3. 选择分类，输入诗句。停顿约 700ms 后查询，中文输入法组词期间不会查询。按 Enter 立即查询，Shift + Enter 换行；也可点击放大镜。设置中可以修改快捷键、关闭停顿自动查询。
4. 出处明确且原句精确匹配时自动填写作者、作品、朝代。有误字或出处冲突时，从右侧卡片选择；“采用原文”图标只有主动点击才会修改诗句。
5. 点击加号收入诗集：首次选择 JSON 保存位置，此后每次收录和编辑都会自动排队写入。需要更换文件时，在设置的“自动保存”行点击文件夹图标。

Key 只保存在当前浏览器的本地存储中，不进入源码、诗集 JSON 或导出的 HTML。换浏览器、清除浏览器数据，或移动到新的文件位置后，可能需要重新填写。移除 Key 可在设置中清空后保存。联调所用 Key 没有写入交付文件。

Tavily 当前提供每月 **1,000 个免费额度**，无需绑卡。应用固定使用 `basic` 搜索，每次请求消耗 1 个额度；停顿触发的每次新查询都会计费于免费额度，五分钟内重复查询会优先使用本页内存缓存。设置会通过 `GET /usage` 显示本月套餐“已用 / 总额”，打开设置时自动查询，也可点击刷新图标更新；鼠标悬停数字可查看剩余额度。按量付费使用情况单独显示，未知值显示为“—”。以接口及账户控制台的实际额度为准。[额度接口](https://docs.tavily.com/documentation/api-reference/endpoint/usage)[官方额度说明](https://docs.tavily.com/documentation/api-credits)

未配置 Key 时仍可离线管理诗集，并从已有摘录中匹配出处。联网失败、额度用完或超时不会清空草稿，作者、作品和朝代均可手动补充。搜索摘要可能不完整，字段为空或存在多种出处时需要核对；搜索结果卡片的外链图标可打开网页参考。API Key 无效时，上游有时不返回跨域错误头，浏览器会显示通用的“检查网络或 API Key”信息。

## 保存、导入与备份

- **本地诗集**：当前打开的是 HTML 内置的诗集快照；内容来自构建时项目目录中的 JSON 诗集。
- **浏览器暂存 · 待保存**：改动和草稿已暂存在浏览器，尚未写入 JSON。缓存仅供恢复，不是唯一存档。
- **已写入文件名**：文件写入及关闭均已成功。选定保存位置后，本次打开页面期间的后续修改会自动写回。每份快照进入串行队列，JSON 序列化、读取检查、文件写入在内嵌 Web Worker 中完成；写入期间可以继续输入和收录。不能传递文件句柄到 Worker 的浏览器使用异步串行队列兼容处理。
- **写入失败 · 待保存**：拒绝授权、磁盘错误或外部修改时保留改动，不误报成功。
- **已导出副本**：已生成下载，请在浏览器中确认下载完成。

支持文件访问 API 的浏览器可直接保存；浏览器要求用户选择一次文件，HTML 无法静默取得任意磁盘路径的写入权限。不支持时保留浏览器暂存，通过更多菜单下载 JSON 保存。重新打开 HTML 后需重新选择 JSON 保存位置，浏览器不一定保留文件授权。[文件访问能力说明](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)

更多菜单的“导入 JSON 诗集”用于加载已有诗集，与自动保存当前诗集不同。打开 JSON 时先预览分类、总数及新增数量，默认合并并跳过五个字段完全相同的条目。整体替换默认下载当前诗集备份。使用文件选择器打开时，可以勾选“以此文件作为保存位置”。如果 JSON 被其他程序修改，自动保存会停止并提示重新打开或另存，避免直接覆盖。

顶部更多菜单提供：

- **导出 JSON 副本**：标准、带缩进的 JSON，便于查看、编辑、版本管理和备份。
- **导出便携 HTML**：将最新诗集嵌入完整页面，复制到另一台电脑后直接打开。未收录的草稿不属于诗集，导出前先收入诗集。
- **导入 JSON 诗集**：打开其他诗集，预览后合并或替换。

顶部只保留设置与更多菜单；“我的诗集”入口位于正文右上角的摘录总数。设置集中管理 API Key、实时额度、JSON 保存位置、搜索快捷键、自动查询和展示范围。

建议日常自动保存 JSON，阶段性导出便携 HTML。清理浏览器缓存或移动 HTML 之前，先确认文件已保存。

## 数据结构

继续使用“分类名称 → 摘录数组”：

```json
{
  "念": [
    {
      "text": "江南无所有，聊赠一枝春",
      "title": "赠范晔诗",
      "author": "陆凯",
      "dynasty": "南北朝",
      "url": ""
    }
  ]
}
```

每个搜索候选底部显示来源域名。采用来自 `gushiwen.cn` 或 `guwendao.net`（含其子域）的候选时，自动填写该页面 URL；其他搜索来源默认留空。来源链接也可以手动填写、修改或清空，只接受完整的 HTTP/HTTPS 地址。编辑和导出保留已有链接。原示例的尾随逗号已修正，诗句文字未改动；导入兼容尾随逗号，导出严格使用标准 JSON。

当前个人诗集规模适合 JSON：便携、轻便、可读，没有数据库安装和迁移成本。查询在内存中按诗句、作者、作品过滤，增改后统一序列化保存。代价是每次写回整个文件，也不适合多个窗口同时写入；若将来增长至数万条或需要多设备同步，再考虑 IndexedDB 加 JSON 备份或独立同步服务。现阶段引入数据库收益有限。

## 分类与阅读

分类支持新增、改名、排序与删除。鼠标左键长按分类约 350ms 后可拖动排序，松手保存，Esc 取消；分类菜单仍可用键盘上移、下移。有内容的分类默认迁移到另一分类；连同内容删除时明确显示数量并再次确认。我的诗集突出诗句正文，支持搜索、编辑、移动、删除；右下角可翻页，每页可选 5、10、20 或 50 则，并记住当前浏览器的选择。同一分类内阻止重复诗句，同一句可放入不同分类。

桌面布局随窗口扩展，最大宽度为 2400px；大屏下三栏宽度、字号和输入区高度相应调整。下方展示条在桌面短句时约 112px 高，与工作台等宽，没有装饰标题。只显示诗句和作者、作品，长内容自然换行并增高。右侧刷新、暂停/继续均为图标按钮；默认每 60 秒轮换，多条时避免连续显示同句，后台标签页暂停。设置中可以限定当前分类。

图标提供提示和可访问名称，支持键盘聚焦、窄屏、触屏及系统减少动画设置。默认 `Enter` 搜索、`Shift + Enter` 换行；设置可切换为 `Shift + Enter` 搜索、`Enter` 换行。`Ctrl/Cmd + S` 可立即保存或重试写入。中文输入法组词期间不会触发快捷键搜索。

## 开屏动画

打开或刷新 HTML 时，默认播放约 3.35 秒的“诗句穿行”：已收录的短句由远及近，最后停驻的一句与下方展示条保持一致。桌面最多 12 组诗句，手机最多 6 组；文本只用于展示，不改动诗集。空诗集使用内置古诗短句，以“余韵”收尾。

- 右上角图标或 Esc 可立即跳过；“设置 → 播放开屏动画”可关闭，并记住当前浏览器的选择。
- 展示条在首屏内且内容高度合适时，诗句会落入展示条；手机或长节选令展示条超出首屏时，中央诗句淡出，不自动滚动页面。
- 动画使用内联的 CSS 透视与原生 Web Animations API，无外部字体、动画库、图片或联网请求。系统启用“减少动画”或浏览器缺少动画能力时直接进入页面。
- 页面在后台或隐藏的浏览器面板中加载时，等到首次可见再播放；播放中切换到后台会暂停，回来后继续。跳过或结束后，切换标签页不会再次触发；刷新或重新打开则开始新的一次。
- 工作台在动画开始前已初始化；开屏期间暂时隔离输入，结束后清理图层、动画和监听器。多余的窗口尺寸通知会被忽略，实际尺寸变化会更新诗句位置与展示条落点，保持播放进度。动画报错会立即放行；独立计时器最多计入约 4.4 秒的前台播放时间，防止动画卡住后无法操作。

## 源码与构建

需要 Node.js 22.12+ 与 pnpm：

```sh
pnpm install
pnpm build
pnpm check
pnpm test
pnpm test:browser
```

构建产物只有 `dist/echoes_of_lyric.html`，无需复制其他文件。脚本、CSS、SVG 和初始诗集全部内联，无 CDN、外部字体或服务端依赖。`pnpm dev` 提供本机预览；修改源码后重新运行 `pnpm build` 并刷新。

- `src/app.ts`：工作台、分类、候选、诗集、保存交互及阅读轮换。
- `src/category-drag.ts`：分类长按拖动、排序预览与取消恢复。
- `src/opening.ts`：诗句穿行、展示条衔接、跳过与异常清理。
- `src/template.html`、`src/styles.css`、`src/icons.ts`：页面、样式和内联图标。
- `src/logo.svg`：A 方案“书签＋引号”的矢量标识；构建时内嵌到页首和浏览器标签页图标，便携 HTML 无需附带 SVG 文件。
- `src/storage.ts`、`src/file-worker.ts`、`src/file-io.ts`：浏览器暂存、下载、后台队列与文件读写。
- `shared/collection.ts`、`shared/matching.ts`：JSON 校验、合并、相似匹配与差异显示。
- `shared/search.ts`、`shared/usage.ts`、`shared/source.ts`：Tavily 搜索与额度查询、摘要提取、来源识别和错误处理。
- `scripts/build.mjs`：esbuild 单文件打包。

搜索请求只包含正在查询的诗句片段和出处查询词，长输入取前 250 字；不发送整本诗集、分类或其他草稿。`POST https://api.tavily.com/search` 使用 Bearer Key，固定 `search_depth: basic`、`auto_parameters: false`，最多 8 个网页结果，不请求原始 HTML，不进行二次网页抓取。API 的回答摘要只在作品名称一致时辅助补充，单独依赖生成摘要的字段不会自动确认。[Tavily Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)
